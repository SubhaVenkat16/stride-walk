# Stride – walking tracker (Android)

Start, pause and stop a walk from the app or from the notification bar. Counts steps while the screen is off, saves every walk, shows Today / Yesterday / Day before, awards badges, and makes shareable cards.

## Get the app on your phone (no computer needed)

1. Put this project in a GitHub repository (main branch).
2. GitHub builds the app automatically (Actions tab, "Build Stride APK"). It takes about 5-8 minutes.
3. Open the repository's **Releases** page on your phone and download **Stride.apk**.
4. Open the downloaded file and allow "Install unknown apps" for your browser when asked.
5. Open Stride, tap **Start walk**, and allow "Physical activity" and "Notifications".

## Notes
- Needs Android 8.0 or newer.
- Distance and calories are estimates based on steps (about 0.76 m and 0.04 kcal per step).
- Photos and videos are copied into the app's own storage.
